⚙️ Paramètres d'envoi

📖 Notice d'utilisation des outils

Guide rapide de chaque outil de l'application. Important : les données préinstallées (profil, compte, entreprises) sont fictives et servent uniquement de démonstration — remplacez-les par vos informations réelles avant tout envoi.

1. 👤 Profil — vos informations personnelles

Remplacez le profil de démonstration par vos vraies informations : nom, téléphone, e-mail, ville, diplôme et spécialité. Ces champs alimentent les messages ({nom}, {email}, {ville}…) et sont visibles par les destinataires. Sans un profil correct, vos candidatures ne peuvent pas aboutir.

2. 📧 Comptes Gmail — l'expéditeur des messages

Ajoutez votre vrai compte Gmail (l'adresse d'envoi) et son mot de passe d'application (16 caractères, généré sur myaccount.google.com/apppasswords). Le compte préinstallé « compte.demo@exemple.com » est fictif et inactif : il sert uniquement d'exemple et ne peut rien envoyer. Activez-le seulement après avoir mis votre vrai compte.

3. 🏢 Tableau de bord — les entreprises cibles

Les entreprises préinstallées sont toutes fictives (marquées « [Démo] »). Supprimez-les (case à cocher → Supprimer) puis ajoutez vos vraies cibles : nom, e-mail de recrutement, catégorie et — très important — un contexte personnalisé qui explique pourquoi vous contactez cette entreprise précisément.

4. 📝 Mes messages — les modèles de lettres

Chaque modèle contient des variables {entreprise}, {contexte}, {nom}… remplies automatiquement. Vous pouvez créer, modifier, dupliquer et supprimer vos propres modèles. Choisissez le modèle par défaut dans les Paramètres d'envoi.

5. 👥 Mes groupes — envois ciblés

Regroupez plusieurs entreprises (par secteur, par zone…) pour leur envoyer le même modèle en un clic, avec le délai anti-spam appliqué entre chaque message.

6. ✂️ Envoi express — un message à la fois

Pour un envoi unique et soigné : choisissez l'entreprise, le modèle, vérifiez l'aperçu, joignez votre CV, puis envoyez. Idéal pour les candidatures importantes.

7. ⚙️ Paramètres d'envoi — anti-spam

Délai entre messages (40 s par défaut, aléatoire 35–55 s conseillé), maximum par heure (100), tentatives SMTP. Ces protections évitent que Gmail ne bloque votre compte pour spam. Ne les désactivez pas.

8. 📨 Réponses & filtres — suivi automatique

L'app vérifie votre boîte via IMAP pour détecter les réponses, classe les e-mails (étiquettes, archive, marque comme lu) selon des règles configurables, et affiche les notifications quand une entreprise répond.

9. 🕓 Historique — tout est annulable

Chaque action (suppression d'entreprise, modification de profil…) est enregistrée et peut être annulée depuis la page Historique.

10. 🛠️ Maintenance — sauvegarde et dépannage

« Actualiser le back-end » recharge les données sans perdre la session ; « Sauvegarde JSON » exporte toutes vos données ; « Importer JSON » les restaure ; « Réinitialiser le log » vide le journal des envois (définitif).

⚠️ Rappels importants
  • Les données préinstallées sont fictives : aucun vrai e-mail ne peut partir tant que vous n'avez pas configuré votre vrai compte Gmail.
  • Utilisez toujours un mot de passe d'application Gmail (jamais votre mot de passe principal).
  • Respectez la loi et les règles anti-spam : n'envoyez qu'à des entreprises pour lesquelles vous avez une candidature légitime.
  • Vos données restent sur votre ordinateur (base locale chiffrée).

🛠️ Maintenance & santé de l'application

Si l'application ralentit ou se comporte bizarrement, utilise ces outils : ils rechargent le back-end sans redémarrer, et ne touchent jamais à un envoi en cours.

✏️ Aperçu avant envoi

🔑 Mot de passe d'application Gmail

⚠️ Important : il faut un mot de passe d'application, pas ton mot de passe Gmail habituel.

Étape 1 — Activer la validation en deux étapes

  1. Va sur myaccount.google.com/security
  2. Clique sur Validation en deux étapes
  3. Suis les instructions (SMS ou appli Authenticator)

Étape 2 — Générer un mot de passe d'application

  1. Va sur myaccount.google.com/apppasswords
  2. Dans « Nom de l'application », tape Candimail
  3. Clique sur Créer
  4. Google affiche un mot de passe de 16 caractères : abcd efgh ijkl mnop

Étape 3 — Colle-le dans l'application

Copie ce mot de passe et colle-le dans le champ « mot de passe d'application ». Clique ensuite sur 🧪 Tester pour vérifier.
