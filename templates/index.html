🔒 Sécurité

🔑 Mot de passe d'application Gmail

⚠️ Important : il faut un mot de passe d'application, pas ton mot de passe Gmail habituel.

Étape 1 — Activer la validation en deux étapes

  1. Va sur myaccount.google.com/security
  2. Clique sur Validation en deux étapes
  3. Suis les instructions (SMS ou appli Authenticator)

Étape 2 — Générer un mot de passe d'application

  1. Va sur myaccount.google.com/apppasswords
  2. Dans « Nom de l'application », tape Candimail
  3. Clique sur Créer
  4. Google affiche un mot de passe de 16 caractères : abcd efgh ijkl mnop

Étape 3 — Colle-le dans l'application

Copie ce mot de passe et colle-le dans le champ « mot de passe d'application ». Clique ensuite sur 🧪 Tester pour vérifier.

💡 Astuce : tu peux ajouter plusieurs comptes Gmail. Ils sont utilisés en rotation automatique à chaque envoi.
